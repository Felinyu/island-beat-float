# Showcase mockups

Rendered product mockups of the Island Beat Float UI, used by the README
instead of raw desktop screenshots. Everything is plain HTML, CSS and inline
SVG - no photos, no personal data, no external assets - so the images can be
regenerated byte-for-byte on any Windows machine with Edge.

The mockups are built from the **actual layout metrics of the 3.1.0 mod**, then
checked 1:1 against the real panel captures in `reference/` (see "Fidelity"
below). The only intended difference from a desktop capture is the clean
gradient backdrop instead of the user's wallpaper.

| Artboard | Query | Output |
| --- | --- | --- |
| Compact taskbar island, circular cover | `preview.html?view=compact` | `../screenshots/compact.png` (770x200) |
| Expanded floating player | `preview.html?view=expanded` | `../screenshots/expanded.png` (800x1450) |
| README hero banner, both states | `preview.html?view=hero` | `../screenshots/hero.png` (1600x875) |

Open `preview/preview.html` in a browser to see every artboard stacked (no
query string = browsing mode).

## Geometry

The 3.1.0 source is authoritative; the reference captures confirm it.

Compact island (`Main.Height = 40`, `Main.CompactWidth = 154` DIP, rendered at
2 CSS px / DIP):

| Element | DIP | CSS in the 770x200 artboard |
| --- | --- | --- |
| Pill | 154 x 40, radius H/2 = 20 | 308 x 80, radius 40 |
| Circular cover | D = H - 2*4 = 32, centre (H/2, H/2) | 64, at 8/8 (concentric with the left cap) |
| Content margins | cover inset 4, top/bottom 4, right 10 | 8 / 8 / 20 |
| Title / artist | 12 / 10, SemiBold / Regular | 22.8 / 19 |
| Text left | content 4 + cover 32 + textMargin 4 = 40 | 80 |
| Equalizer | 5 bars, 2.4 wide, 0.75 gap, 16 high, right inset 10 | 4.8 / 1.5 / 32 / 20 |

Expanded panel (`Main.ExpandedWidth = 360` DIP; visible surface = 324 x 578 DIP
after the 18 DIP host shadow margin and 20 DIP surface gap; rendered at
10/9 CSS px / DIP):

| Element | DIP | CSS in the 800x1450 artboard |
| --- | --- | --- |
| Glass surface | 324 x 578, radius 46 | 360 x 642.22, radius 51.11 |
| Artwork | inset 20, 284 square, radius 16 | 22.22, 315.56, 17.8 |
| Content column | left 38, width 248 | 42.22, 275.56 |
| Title / artist | 16 Bold / 13 | 17.78 / 14.44 |
| Progress / times | 6 high at +91, text 11 at +103 | 6.67 at 447.78, 12.22 at 461.11 |
| Transport | 3 buttons 52 x 58, glyphs 32 / 38 | 57.78 x 64.44, 35.56 / 42.22 |
| Volume row | track at +218, 192 wide, icons 18 / 20 | 588.89, 213.33 wide, 20 / 22.22 |

Colors come from the dark-mode XAML brushes: primary `#FFFFFF`, secondary
`rgba(255,255,255,0.784)`, progress track `0.204`, volume track `0.314`,
volume fill `0.91`, volume icons `0.847`; the equalizer accent is the README
green `#6EB85A`. Transport glyphs are the mod's own Segoe Fluent Icons
codepoints (`EB9E`, `E768`, `EB9D`; volume `E992`, `E767`).

Two small deliberate deviations keep the screenshot readable at README size:

- The idle title "Island Beat Float" is 5% smaller than the real 12 DIP (and
  gets -0.03em tracking), because at the user's 154 DIP width the real title
  would ellipsize; this keeps the full title visible without changing the pill.
- The compact text stack is nudged up ~2 DIP to match the XAML line-box
  baselines (CSS font line boxes centre differently than XAML ones).

## Rebuild

Requires Windows, Microsoft Edge (headless) and Python 3 with Pillow:

```powershell
python preview/build.py
```

`build.py` renders each artboard with Edge at
`--force-device-scale-factor=2`, crops the padded viewport back to the artboard
rectangle and writes the PNGs into `screenshots/`. Single-view artboards are
anchored at a fixed `(40, 40)` CSS offset and the window is the artboard plus
2 x 40 px: Edge reports a viewport a few pixels wider than `--window-size`
below ~500 px, which would shift a flex-centred artboard.

## Fidelity

`preview/reference/` contains the real 3.0.0 panel captures from the git
history (compact 390 x 105 px, expanded 645 x 1197 px). They are only used as
a measurement reference - the README uses the rendered mockups.

```powershell
python preview/compare.py
```

builds 1:1 side-by-side comparisons at the captures' own pixel scale into
`preview/compare/` (`compact.png`, `expanded.png`): the real capture on the
left, our render on the right. The compact render is 2x the capture scale and
is downscaled for the comparison; the expanded render's glass surface is
normalised to the capture's 645 px width. Differences that remain are the
clean gradient backdrop, the 3.1.0 circular cover (instead of the 3.0.0
rounded square) and the generated abstract artwork instead of a real cover.
