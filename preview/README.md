# Showcase mockups

Rendered product mockups of the Island Beat Float UI, used by the README
instead of raw desktop screenshots. Everything is plain HTML, CSS and inline
SVG - no photos, no personal data, no external assets - so the images can be
regenerated byte-for-byte on any Windows machine with Edge.

| Artboard | Query | Output |
| --- | --- | --- |
| Compact taskbar island, circular cover | `preview.html?view=compact` | `../screenshots/compact.png` (780x200) |
| Expanded floating player | `preview.html?view=expanded` | `../screenshots/expanded.png` (800x1450) |
| README hero banner, both states | `preview.html?view=hero` | `../screenshots/hero.png` (1600x875) |

Open `preview/preview.html` in a browser to see every artboard stacked (no
query string = browsing mode).

## Rebuild

Requires Windows, Microsoft Edge (headless) and Python 3 with Pillow:

```powershell
python preview/build.py
```

`build.py` renders each artboard with Edge at
`--force-device-scale-factor=2`, crops the 40 px padded viewport back to the
artboard rectangle, rounds the corners and writes the PNGs into
`screenshots/`. The artboards use Windows system fonts only (Segoe UI
Variable / Segoe UI, Segoe Fluent Icons for the transport and volume glyphs).

Design notes:

- The compact cover is a circle whose diameter equals the pill's inner height
  and whose centre is concentric with the pill's end cap, matching the 3.1.0
  circular-cover design.
- The cover art is an abstract mesh gradient (soft colour orbs, gloss,
  vignette) rendered from SVG gradients, mirroring the mod's generated
  artwork pipeline. It is deliberately not a photo.
- The dark purple/blue backdrop, glass materials, green `#6EB85A` equalizer
  accent, progress/times row and transport/volume row follow the real UI
  layout; colours and typography live in the `<style>` block of
  `preview.html`.
